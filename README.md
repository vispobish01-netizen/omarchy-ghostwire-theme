# Ghostwire

A dark cyan/purple "instrument panel" theme for Omarchy.

## Installation

```
omarchy-theme-install https://github.com/vispobish01-netizen/omarchy-ghostwire-theme.git
```

Then pick **Ghostwire** in the theme menu, or run:

```
omarchy theme set ghostwire
```

Terminals, Neovim and VS Code colors are generated by Omarchy from `colors.toml`. Cycle wallpapers with `omarchy theme bg next`.
